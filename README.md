# Duels

A Minecraft plugin for Paper servers, developed using the Paper API.

## Overview

Duels is a personal project focused on developing a player-versus-player duel system for a Minecraft server.

The plugin was designed to let players create public or private duels, compete in configurable arenas, and wager in-game currency as a prize.

## Planned Features

- **Public and private duels:** create challenges available to everyone or directed at a specific player.
- **Inventory GUI:** browse available duels and access duel creation menus.
- **Configurable arenas:** define spawn locations for duel participants.
- **Economy integration:** use Vault to interact with the server's economy.
- **Duel management:** handle duel creation, acceptance, completion, and player disconnections.

## Technologies

- Java 21
- Paper API 1.21.4
- Vault API
- Gradle

## Project Status

This project is an unfinished personal prototype and is no longer actively developed.

It was developed as a learning experience focused on Minecraft plugin architecture, event handling, inventory GUI development, player interactions, and third-party API integration.
